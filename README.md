# navidrome-ubuntu-install

Installs Navidrome on Ubuntu via the official .deb release, verified by SHA256 checksum.

## Usage

```bash
chmod +x install_navidrome.sh
sudo ./install_navidrome.sh --dry-run
sudo ./install_navidrome.sh
```

See the comments at the top of `install_navidrome.sh` for full details
(requirements, options, security guarantees, known limitations).
